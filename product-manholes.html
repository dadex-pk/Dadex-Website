Product Overview

A complete system for underground sewer access.

The Dadex manhole system is built from compatible chamber bases, rising pipes, seals, covers, and supporting components. Designed as a coordinated system, it provides safe access to underground sewerage and drainage networks while simplifying installation and configuration.

Application Areas

Where Manholes are used

  • Deep sewerage network access
  • Highway and municipal drainage
  • Pedestrian areas (A15/B125 covers)
  • Traffic areas (D400 covers)

Multiple cover and frame configurations are available to suit specific load requirements.

Installation

Proper installation for safe underground access.

Because the manhole is a modular system, components must be assembled carefully to ensure structural integrity and watertightness.

Installation considerations

  • Ensure the chamber base is properly bedded.
  • Fit reducing rings and seals correctly.
  • Select the correct cover class (A15, B125, D400) for the surface load.
  • Ensure the frame and cover sit flush with the finished surface level.

Refer to the relevant product documentation for detailed installation instructions.
